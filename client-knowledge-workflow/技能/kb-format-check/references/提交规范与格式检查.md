# 提交规范与格式检查

## 推荐交付形式

| 内容 | 推荐格式 | 检查点 |
|---|---|---|
| 产品说明、服务流程、政策、FAQ | 带层级标题的DOCX；内部可用Markdown | 一份围绕一个主题；适用对象、版本、生效时间；段落有足够上下文 |
| 产品参数、价格、门店名录 | XLSX或CSV | 一行一个对象；列名、单位、适用条件；不要以颜色或位置作为唯一含义 |
| 证照、专利、检测报告 | 原电子文件或完整清晰扫描PDF/图片＋索引 | 所有页及附件；清晰可读；索引编号关联原件；整理文本不替代原件 |
| 场地和产品照片 | 独立JPG/PNG等原图＋说明 | 主体、地点、日期、画面内容与可公开范围；照片编号关联说明 |
| 聊天、回访、工单 | 有顺序和角色的文字/HTML/JSON及媒体附件 | 会话/消息ID、时间、角色、附件对应、缺失标记；保留问题到处理结果的上下文 |
| PPT、海报、旧宣传稿 | 保留原件，关键事实另列可编辑文本 | 图表、脚注、价格条件和证据关联不可遗漏；标明历史版本 |
| 网页链接 | 原始链接＋标题/来源/日期/访问日期 | 能否访问，是否需登录，内容是否变动；访问失败不当作已核实 |

不统一强制转成PDF。扫描件先OCR后对照原图校核；价格、数字、型号、单位、否定词、日期与证号重点复核。OCR置信分数不能代替对照。

## Excel预警

十个工作表不是天然不合格。区分结构化多表与图文画布。检查所有工作表：字段是否明确、同列含义是否一致、多表是否有稳定主键、图片与产品是否关联、是否有隐藏行列/工作表、合并、公式、错误值和外链。

出现嵌入图、WPS DISPIMG/IMAGE公式、浮动图或合并格，先列“需要检查解析与图文对应”；不能直接声称图片已经丢失。若实际解析已证实丢失重要信息或关系，则阻断该部分入库，要求独立图片＋文字说明＋编号关系。CSV不能保留图片、多工作表和复杂格式，转换前明确损失。

## 自动预检的使用

`scripts/preflight.py` 是本技能的只读辅助工具，检查文件清单、哈希、常见文件签名、部分图片尺寸和Office结构。它不做OCR、语义审核、图片真实性验证、证书查询或平台导入。

```powershell
python -X utf8 "技能目录/scripts/preflight.py" --input "客户材料目录" --output "项目输出目录/格式预检.json"
```

输出目录放在材料目录之外；默认不跟随符号链接。可执行脚本、未知扩展名和无法读取项不执行，列待检查。对大文件或异常压缩包设上限并报告跳过原因，不假装扫描完成。

预检后仍需实际打开：正文/扫描件、表格内容、证照原页和图片。使用当前可用的文档、表格、PDF或视觉工具；缺少工具就列未检查，不自动安装工具或上传客户文件。加密文件请客户提供可读副本，不尝试绕过保护。

## 输出与通过条件

按材料输出“可读取/读取失败/待人工检查”，并将结构风险写入问题单。明确哪些只是风险信号、哪些已经观察到信息损失。格式通过只表示可读与结构可用，不表示事实可靠或业务合格。

对目标平台检查实际解析结果：标题与层级、表格表头/单位/脚注、图片说明、页序、章节、来源定位；准备一个带例外条件的问题测试跨段关联。平台未测试时标“本地格式预检完成，平台解析待验证”。
