# 六类内容质检

## 通用判定

检查对象、主体、时间、版本、场景、完整性、证据范围和使用权限。找矛盾前先统一型号、区域、渠道、数量、税费与有效期；不能仅凭表面不同报冲突。每个结论写出源位置，必要时引用短句供客户判断。没有资料不补事实，内容缺失不自动要求客户补所有类别。

## 覆盖表

| 类别 | 内容项与实质检查 |
|---|---|
| 产品与服务 | 手册/目录：型号、名称、参数、单位、版本与适用工况；报价/价目/套餐：税运费、数量、渠道、地域、套餐包含与不含、时间；服务流程/合同：责任、交期、验收、退款、售后和包外边界是否一致；专利/检测：另按证据规则核查 |
| 市场与价格 | 宣传册/海报/品牌PPT：夸大或无依据的能力与效果；促销：条件、名额、适用对象、门店、起止时间；销售培训：内部策略与对外承诺分开；地址：营业状态；发布链接：可访问性、旧价格/旧承诺是否需纠正 |
| 品牌与公司 | 执照/简介：主体、成立/品牌创立时间不同概念；故事/创始人：关键经历依据；新闻：原报道和转载去重，报道不能证明所有主张；奖项：授予方、年份、级别、适用主体；账号：归属；场地照片：见照片规则 |
| 客户与反馈 | FAQ/话术：完整答案、适用条件、例外、转人工与确认状态；聊天：连续上下文、角色、原话与推断；评价：可回溯来源、真实性待核验、可使用范围；回访：对象、问题、处理、结果与未解决项；复盘/丢单：客户明确原因与销售归因分列；案例：背景、方案、周期、结果测量方法与基线、授权范围，不能把相关性自动变成因果 |
| 竞争与行业 | 竞品PPT/官网：对比相同型号/条件/时点，负面断言要有依据；研报：作者、年份、样本与口径；政策法规：发布主体、现行/废止状态、地区和行业；培训/展会资料：主办方、时间、事实与意见区分；引用外部内容注明来源与使用限制 |
| 合规与红线 | 禁用词：来源依据、场景与替代表达；监管/平台规则：版本、生效日、适用范围；免责声明：不与主文承诺相冲突，不据此认定风险已消除；已审话术：审核人、日期、渠道、对象，旧审核不能自动覆盖新用途 |

## 照片规则

照片有两种目标：证照可辨读，场景可说明事实。证照检查整页边缘、页号、编号、签章或电子签发信息、附件；场景检查清晰度、曝光/反光、遮挡、裁切、重复、主体标识、图文一致、时间与归属说明、可公开范围。没有统一像素合格线；按原尺寸放大是否足以读清关键内容，记录检查方式。

- 制造：正大门与标识、厂区全景、主要车间、关键设备、生产过程、质检区域、仓储与发货。按声称的能力选拍，不要求全部现场都开放。
- 门店：门头与周边定位、接待区、实际经营/服务区域、主要设施、经允许的真实服务过程。
- 专业服务：办公或交付场景、流程/成果展示，经允许的项目现场；不强求厂房照片。

说明表字段：图片编号、文件、主体、地点、拍摄日期或待确认、内容、拟支持的事实、公开范围。照片不能单独证明产权、产能、实际效果或地点真实性；发现疑似不一致只记疑点与核实要求，不凭视觉直接定伪造。

## 客户记录规则

检查重复/选择性抽样、截断、缺失语音和附件、时间缺口、角色混淆、报价后续条件、投诉后续处置。一次性让步、历史活动、销售错误承诺不转成现行标准。大量好评不能替代来源核验，单一评价也不证明普遍效果。

“客服说可以退款”和“合同不退款”先核对时间、订单和例外授权；没有解释则提交业务负责人确认，不能擅自选择更利于成交的一条。

## 输出限制

最终列：覆盖矩阵（哪些实际查过）、问题与补件单、证据台账、待访谈主题、可进入后续整理的内容范围。证据专项见另一参考文件；证号格式正常、签章看起来正常或网站查到编号，均不等于所有内容真实且可支持宣传。
