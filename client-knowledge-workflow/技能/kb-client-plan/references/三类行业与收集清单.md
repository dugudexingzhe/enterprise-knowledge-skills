# 三类行业与收集清单

## 企业画像最小输入

公司名称是入口。结合城市、官网、客户给的主营信息识别主体；公开资料不足时先输出初判及依据，再问最小确认问题。不要把经营范围直接当主营，不能仅凭名称给企业贴行业标签。制造＋品牌＋门店可组合模板，分别记录角色。首批不覆盖的高监管细分行业，先形成待核实专项要求，不套用通用模板声称合规。

画像字段：企业主体、品牌、城市、官网、主营产品或服务、经营模式、主要客户、区域、优先场景、拟回答的业务问题、权威资料负责人、目标平台。未知项可留“待确认”，不因此阻止先做通用准备。

先确认知识库用于GEO公开内容、内部销售、客服或培训；未说明时暂按内部准备处理，公开范围待确认。公开调研信息与客户确认事实分别列。

## 按场景排序

首批必需：能说明主体与业务、主要产品/服务、当前价格或报价边界、交付和售后、核心FAQ、适用红线的材料。按业务提供：专利、检测、许可、门店、厂区、渠道授权等。后续补充：研报、展会、旧培训、历史新闻。具体优先级以客户首个场景调整，不要求所有企业提交所有证书。

| 业务类型 | 重点知识 | 主要知情人 | 首批应能回答的问题 | 特别核查 |
|---|---|---|---|---|
| 制造/OEM | 型号参数、工艺、适用工况、交期、起订量、定制边界、质检、生产与品牌关系 | 产品/技术、销售、质检、生产负责人 | 能否满足某工况；多久交；报价含什么；哪些证据支持某项性能 | 报告对应型号/样品；OEM主体与授权；样品检测不泛化全系列；产能主张有依据 |
| 门店服务 | 门店信息、项目、价格、预约、服务流程、退款售后、投诉处理 | 店长、前台、服务负责人 | 哪家店提供；适用谁；如何预约；套餐限制；异常找谁 | 门店仍营业；促销时间/适用店；现场照片归属；服务禁忌或适用条件按行业专项确认 |
| 专业服务 | 服务范围、交付物、实施前提、项目流程、验收、变更、支持边界 | 项目经理、顾问、售前、交付负责人 | 具体交什么；客户配合什么；何时算完成；包外如何处理 | 人天/周期/计价口径；旧项目个案不能变标准承诺；案例结果与归因证据 |

## 六类收集底表

对每项按首批必需/按业务提供/后续补充标记，并给客户写清用途和合格示例。数量先看覆盖，不强制原图数量。

| 类别 | 项目 | 整理与补充重点 |
|---|---|---|
| 产品与服务 | 产品手册、产品目录、报价单/价目表、套餐规格表 | 可编辑源文件优先，保留原版；型号、单位、适用条件、生效时间、税运费明确 |
| 产品与服务 | 专利、检测报告 | 原始完整文件＋索引；一列编号仅是线索，不能当证据齐备 |
| 产品与服务 | 服务流程、合同模板 | 标准版本、双方责任、交付验收、售后与变更边界；合同按授权范围处理 |
| 市场与价格 | 宣传册/海报、促销方案、销售培训资料、品牌介绍PPT | 版本、活动条件、结束时间、现行/历史口径；承诺能够回查依据 |
| 市场与价格 | 店铺/门店地址、已发内容链接 | 地址与营业状态；渠道、发布时间、可访问性及需更正内容 |
| 品牌与公司 | 营业执照、公司简介、品牌故事、创始人介绍 | 主体关系、关键时间、经历依据；不要求提供高敏感身份证件 |
| 品牌与公司 | 新闻报道、获奖证书、厂区/门店照片、各平台账号链接 | 原来源、奖项范围、照片说明及权属关系、官方账号归属 |
| 客户与反馈 | 客服话术/FAQ、客服聊天、客户评价截图 | 真实上下文、来源、日期、适用条件；先脱敏；正式答案由负责人确认 |
| 客户与反馈 | 售后回访、销售复盘/丢单、成功案例 | 过程与结果、正反样本；原因区分事实与人员推测；案例使用范围 |
| 竞争与行业 | 竞品分析PPT、竞品官网、行业研报、政策法规 | 原始来源、型号、时间、统计口径与现行效力；客户宣传不当中立事实 |
| 竞争与行业 | 行业培训、展会会议资料 | 主办/作者、时间、适用背景；观点与事实区分 |
| 合规与红线 | 禁用词、监管要求、平台规则、免责声明、审核过的对外话术 | 规则依据与适用渠道、版本、审核人；同一法规仅维护一份权威记录 |

## 客户版清单写法

开头说明本次优先场景。先列最重要的一小批材料及用途，随后列按业务提供和可后补材料。表头用“材料/为什么需要/怎么交/示例/现状与负责人”。已有原件直接收取，内部整理不转嫁客户。

统一附言：暂时没有的材料，请说明是未发生、未记录、未找到、无法提供还是不适用；我们会优先从已有记录整理，再针对缺口访谈。Excel只用来整理有字段的数据，照片及证照另交原文件并用编号关联。
