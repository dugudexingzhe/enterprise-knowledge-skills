# 证据与证照核验

## 四个不同问题

1. 完整性：是否具备核查主张所需的原件、全部页和附件？
2. 来源与真实性：谁提供、谁签发、官方或发证方能否对应？
3. 当前状态：是否在适用日期有效，是否存在暂停/注销/撤销/终止等？
4. 用途匹配：证明对象、型号、范围和所声称能力是否对应？

每项分别记录。没有资格完成的专业判断留给客户对应负责人或专业人员，不将智能体资料核对写成法律鉴定。

## 分类核查

| 类别 | 应收和核查 | 常见错误 |
|---|---|---|
| 主体证照/行政许可 | 完整证照、主体、统一社会信用代码、许可范围/地点、日期/状态，适用时查询主管部门 | 营业执照不证明所有许可；总部许可不自动覆盖各门店 |
| 产品认证 | 证书及附件、产品/型号、委托人、生产者、生产企业、标准、状态与适用范围 | 以一款产品认证覆盖所有产品；借关联主体证书 |
| 管理体系认证 | 获证组织、范围、场所、标准、周期、状态、发证机构及查询方式 | 用企业体系证书支持未经证明的单品性能或效果 |
| 人员资格 | 证书、持有人与企业业务关系、注册/执业范围、状态；最小化处理个人信息 | 个人资格直接等同企业资质 |
| 知识产权 | 权利类型、名称、权利人、申请/授权/登记、现行状态、与产品关系 | 申请当授权；发明人当权利人；编号列表当原件 |
| 品牌/经销授权 | 授权双方、权利基础、地区/渠道/产品、期限、转授权及用途边界 | 过期授权、口头授权、代理商当生产厂家 |
| 荣誉/协会材料 | 颁发主体、规则或评选依据、年份、获奖主体、范围与可用措辞 | 会员证当监管许可；地方/年度荣誉扩成全国永久能力 |
| 检验检测报告 | 全页及更正/补充件、编号、样品/型号/批次、委托方/生产方、日期、机构、项目/方法/标准、数据/结论、签发与限制 | 只有编号；少结果页；只检部分项目却宣称全部性能；跨型号、跨主体使用 |

以上按行业和用途选择，不把每类证书设为所有客户必交。CMA、CNAS等标识及能力范围按报告用途和适用要求核对，不统一要求所有报告同时带两种标识。

## 专利

必须区分发明、实用新型、外观设计及申请中/授权后状态。核对专利号、名称、申请日/授权日、当前权利人、当前法律状态与客户权利关系。证书反映授权时状态，现行状态需查相应官方记录或可验证的证明；不能只按理论最长保护期推算。

查询不能访问、登录受限、查询无结果或客户仅有列表时记具体状态，不补“有效”。实际对外使用前按使用日期复核。不能把外观设计或申请受理当成技术性能证明。

## 检测报告时效

不默认一年有效，也不默认永久有效。记录报告是否明示期限；结合行业法规/认证规则、具体用途（招投标/客户采购/平台入驻等）要求、标准变更、产品型号/配方/工艺/批次变化，以及机构撤回或更正信息确定是否需重检或补证。

旧报告可以保留历史证据价值，同时不适合证明现售产品某项主张；没有统一期限依据时写“本用途时效要求待确认”，不要编截止日期。报告反映送检样品及所检项目，不直接推出全系列、所有批次或长期效果。

现行报告核对参照《检验检测机构监督管理办法》对应适用范围。电子签章与纸质签章可能不同，不能因看不到手写签名就直接否定合法电子报告。核查机构在签发时的资格/能力范围、报告是否有更正/撤回，同时按当前用途检查状态。

## 查询与留痕

先识别证据类型，再找相应主管部门或发证方渠道，不能所有材料都送认监委。认证证书按2026年9月30日起实施的分类查询规则核实；自行制定规则的认证证书不以统一平台搜不到判假。

保存核验字段、查询渠道/页面、查询时点、观察结果、未覆盖范围和必要截图位置。验证码或登录要求由有权限的人处理，无法完成则待外部核验。外部查到编号最多支持相应登记字段，不能据此鉴定客户提交全文未被篡改。依据见[平台与核验来源](平台与核验来源.md)。
