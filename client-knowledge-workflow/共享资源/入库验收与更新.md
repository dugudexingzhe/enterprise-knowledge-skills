# 入库验收与更新

## 两层验收

资料预验收：本地能读，关键事实有来源及适用条件，候选/正式状态和使用范围明确，关键问题已解决或隔离。平台实测：在实际目标平台、版本、配置和权限下试导入，查看解析、检索、回答与引用。没有实际导入证据，不得把资料预验收写成平台已验收。

仅获得“整理材料”授权时准备导入清单和测试题；实际外部上传、建库和修改权限按当前已有明确授权处理。公开材料和内部材料根据权限与检索能力选择隔离方式；平台做不到可靠隔离时不要混入同一可公开调用范围。

## 试导入与解析复核

选覆盖文本、表格、扫描证照、图片、FAQ的代表样本；不存在的类型不强行造客户资料。记录平台、入口、版本/套餐、解析设置、模型配置、导入批次、材料版本及时间。未知配置标未知。

检查：材料是否完整、表格表头/数值/单位/脚注、图片与描述、页序及章节、被隐藏信息的处理、来源定位、分块是否拆散条件/例外。复核关键内容对照原件，不能用上传成功或能生成回答代替。

## 业务题集

| 题型 | 预期检查 |
|---|---|
| 事实直问 | 主体、型号、参数、单位和现行状态准确，引用支持答案 |
| 价格/条件 | 报价单位、税运费、数量、渠道、时间、包含与不包含项没有丢失 |
| 场景与比较 | 按适用条件判断，不把不同产品/场景混答 |
| 证据适用 | 不用申请中专利说已授权，不跨型号使用检测，不把旧状态说当前有效 |
| 售后与例外 | 标准流程和授权例外分清，达到升级条件时转人工 |
| 版本与冲突 | 不无条件合并冲突；现行/历史答案能区分 |
| 无依据/诱导 | 没有材料就说明缺依据或追问，不虚构事实、日期或承诺 |
| 使用范围 | 内部/受限内容不进入公开结果，无关用户不能访问 |
| 表格/图片 | 实际能定位相关内容与关联对象，不用图片文件名猜答案 |

题目来自客户真实业务问题及已发现风险，覆盖关键知识和不同问法。关键价格、主体、资质误用、数据泄露与重大错误承诺应阻断受影响范围；不以总平均分冲淡。普通问题按场景约定验收要求，不能未经约定承诺固定准确率。

记录每题的预期事实及来源、实际回答与引用、通过/失败/未测、失败原因（原材料/解析/检索/生成/权限）及修正后复测证据。没有平台访问时只写预期答案和“未测”，禁止伪造实际回答。

## 交付与更新

交付包按需要区分：原始证据、整理后的正式知识、待确认候选、问题与补件单、验收记录。原件保留，禁止入库材料排除；正式知识可通过元数据、独立文件或平台权限实现，不预设所有平台有相同字段能力。

每个知识主题指定业务负责人或明确待指定。按风险设置复核触发：价格/促销变更、产品型号/工艺变更、政策更新、证照状态变化、重复客诉、FAQ纠正。临时活动写截止日，没依据不填永久有效。

变更后定位受影响K/M/T编号，更新知识版本、证据状态并复测相关题。对外GEO仅验收可公开事实和内容依据；外部平台抓取、推荐或经营效果需另设观察和评估，不与内部问答验收混同。
