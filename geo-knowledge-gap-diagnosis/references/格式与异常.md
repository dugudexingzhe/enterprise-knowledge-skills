# 格式、异常与范围

## V1.0 实际提取范围

| 格式 | 提取与定位 | 仍需人工/其他工具的部分 |
|---|---|---|
| MD/TXT/RST/LOG/JSON/JSONL/YAML/XML/HTML | 原文逐行；UTF-8/BOM、带BOM UTF-16、GB18030严格解码 | HTML不运行JS也不访问外链；其他未知编码登记失败 |
| CSV/TSV | 全部记录；记录号及结束物理行；单元格用分隔符拼接 | 不执行公式；不推断空值含义 |
| DOCX | 主文档段落、表格单元格、页眉页脚、脚注尾注和批注文本 | 不提供虚构页码；图片/对象、修订、altChunk、文本框/嵌套表格、图表/SmartArt登记部分读取；复杂样式/布局仍可能影响阅读 |
| XLSX | 所有工作表包括隐藏表；逐非空单元格，只读打开并重置维度 | 不计算公式；有公式/图片/图表/对象则部分读取；不依赖旧缓存作事实 |
| PDF | 所有页的文本层，页码 | 加密失败不自动解密；无文本页登记部分读取；图片未OCR；复杂表格阅读顺序可能不准确 |
| PPTX | 幻灯片文本及表格文本、备注文本 | 未做视觉解释，图片/图表/对象部分读取；备注位置保留XML部件名，不猜对应页 |
| 图片/音频/视频、旧版DOC/XLS/PPT、压缩包及其他格式 | 全部清点、算hash并登记未支持 | 无内置OCR、语音识别、视频理解、压缩包递归展开；不能声称内容已读 |

文件名、目录名、大小、hash不是业务证据。外部链接、快捷方式、符号链接及Windows目录联接不跟随；记录边界，避免超出授权和循环。普通隐藏目录和隐藏文件照常扫描。目录链接对应条目纳入清单并标扫描不完整，但无法知道其内部文件总数，不虚构完整率。

## 状态与完成

- pending：已清点，尚未尝试解析；需续跑，禁止正式finalize。
- parsed：支持的提取器正常返回非空文本；不是内容真实性保证。
- partial：部分文本可读，但有页/公式/图片/修订等未解析内容。
- empty：没有可提取正文。
- failed：损坏、编码、权限、缺依赖或其他读取异常，保留异常类型和消息。
- unsupported：格式未支持，不能混同成功读取。
- blocked_link：链接目标未读取。
- duplicate：相同内容副本；文件清单 effective_status/effective_error 继承规范来源的实际结果。

文件清单在第一次解析前落盘，每个批次后保存。进程被关闭时本批可重新执行，不覆盖原始文件。续跑和最终输出会再次枚举、计算源树hash；变化则报错，使用新目录重扫。提取语料有单独hash，改动后拒绝引用。

## 限制

分批按文件数进行，审阅按文本字符数分包；不设资料文件数上限，也不抽样。不保证单个超大PDF/XLSX/文本文件在任意内存上可解析。清点hash、续跑与最终验证都需读取全树，大量资料耗时随总体积增长。目录清单/语料索引需要内存；超大文件应在获准后另提供可读副本，不改原件，不静默截断。

没有内置解析超时；操作系统杀进程/断电时通过pending和续跑处理，不能保证即时异常报告。文件系统并非原子快照，检查期间持续变化的目录应先由用户提供稳定只读快照。不扫描网络云盘未落地内容、NTFS附加数据流或压缩包内部文件，这些均不属于普通本地文件树可读文本覆盖。

存在任何未完整读取资料时，无依据需求统一保守标“无法判断”。有独立充分依据的需求可标“充分”，但全报告注明未读文件仍可能改变结论。有部分相关依据则可标“部分”，明确可读信息和未读限制。
