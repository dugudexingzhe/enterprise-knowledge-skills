# 模拟测试

全部企业、产品、金额与案例为虚构。本轮不读取真实客户目录。

执行自动测试：

```text
python -m unittest discover -s tests -v
```

测试会在系统临时目录自行生成模拟数据，不覆盖本包附带样本，结束自动回收。需要requirements.txt；没有python-pptx时，PPTX生成器使用仅文本的最小XML容器测试解析器，不能据此证明对任意PPTX包兼容。

重新生成一套可查看样本（目标必须是新目录）：

```text
python tests/make_fixtures.py "新的模拟资料目录"
```

`完整与缺口/`：多层/隐藏目录、MD/TXT/CSV/JSON/DOCX/XLSX/PDF/PPTX、重复副本；支持充分、部分、缺失、冲突和共性缺口去重。

`不可读与重复/`：增加损坏DOCX/PDF、旧版DOC、无效编码、空文件、占位图片/视频、无文本PDF、含公式XLSX。图片/视频是明确的测试占位字节，只用于验证登记未支持，不是媒体解码能力测试。

自动测试使用固定的模拟诊断决策验证脚本约束，不能证明模型自由推理准确率。另由当前Codex实际阅读SKILL.md与完整审阅包后生成分析和报告，结果见测试结果.md及examples/；不将该过程称为独立盲测，也不将同一脚本运行等同多平台验证。
